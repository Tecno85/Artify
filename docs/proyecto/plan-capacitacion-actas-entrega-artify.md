## 1. Introducción

En esta evidencia presento el plan con el que capacitaré a las personas que usarán Artify, el acta para registrar su satisfacción y el acta con la que formalizaré la entrega del software. Organicé los tres instrumentos en el orden en que se aplican durante la implantación: primero preparo y realizo la capacitación, después compruebo la comprensión del participante y, por último, verifico y entrego el producto.

La entrega debe involucrar a las partes interesadas y dejar información verificable sobre el producto, la aceptación y las responsabilidades posteriores. Este enfoque es coherente con el marco de procesos del ciclo de vida del software de ISO/IEC/IEEE 12207:2026. Además, los criterios de aceptación permiten valorar si el producto cumple su propósito, de acuerdo con el modelo de calidad de ISO/IEC 25010:2023.

## 2. Objetivos

### 2.1 Objetivo general

Planificar la capacitación y formalizar la satisfacción y la entrega de Artify mediante instrumentos claros, verificables y adecuados para las personas que usarán o recibirán el sistema.

### 2.2 Objetivos específicos

- Explicar el acceso y las funciones principales de Artify mediante una demostración práctica.
- Comprobar que el participante puede completar un flujo básico de edición y descarga.
- Registrar la satisfacción, las dudas y las observaciones surgidas durante la capacitación.
- Identificar el software, la documentación y los demás componentes entregados.
- Dejar constancia de la conformidad, los pendientes y las firmas de las partes.

### 3.2 Resultados esperados

Al terminar la capacitación espero que el participante pueda:

- Ingresar a Artify y reconocer las áreas principales de su interfaz.
- Cargar una imagen compatible y aplicar al menos una transformación y un filtro.
- Deshacer o rehacer un cambio y descargar el resultado en un formato permitido.
- Cerrar la sesión de manera segura.
- Gestionar cuentas de usuario, si participa con el rol administrador.
- Consultar los manuales y solicitar ayuda cuando la necesite.

### 3.3 Agenda

| Momento | Actividad | Tiempo |
| --- | --- | ---: |
| Inicio | Presentación, propósito y comprobación de acceso | 5 min |

La capacitación operativa tiene una duración de 60 minutos. Cuando participa una persona con rol administrador, agrego un bloque específico de 15 minutos, para una duración total de 75 minutos.

### 3.4 Metodología y evaluación

Realizaré una explicación breve, demostraré cada operación y luego pediré al participante que repita el flujo con una imagen de prueba. Evitaré usar datos personales o imágenes confidenciales. Como materiales de apoyo emplearé la guía del usuario operativo y, si aplica, la guía del usuario administrador de Artify.

Consideraré cumplido el objetivo práctico cuando el participante pueda, con orientación mínima:

1. Iniciar sesión.
2. Cargar una imagen JPG, PNG o WebP válida.
3. Aplicar y confirmar una herramienta de edición.
4. Deshacer o rehacer un cambio.
5. Descargar el resultado.
6. Cerrar la sesión.

Registraré el resultado como **cumplido**, **cumplido con apoyo** o **pendiente de refuerzo**. Las dudas y acciones pendientes quedarán consignadas en el acta de satisfacción.

### 5.2 Producto entregado

Yo, Iván Darío Madrid Daza, hago entrega de **Artify**, una aplicación web para cargar, transformar y descargar imágenes. El producto incluye un frontend desarrollado con HTML, CSS y JavaScript, una API con Node.js y Express, y persistencia en PostgreSQL.

La versión entregada permite registrar e iniciar sesión, editar imágenes mediante recorte, redimensionamiento, rotación y filtros, utilizar el historial de cambios, convertir y descargar archivos, guardar preferencias y consultar datos básicos de actividad. También incluye un panel protegido para gestionar cuentas de usuario.
